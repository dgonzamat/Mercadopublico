# UAP Codex v1.0.0

Primer hito público estable de **UAP Codex** — un archivo editorial de fenómenos aéreos no identificados (UAP) tratados como caso institucional, no como folclore.

🔗 **https://uapcodex.org/**

## Qué es

Un corpus curado de **321 casos** documentados entre el siglo XVI y 2026, cada uno anclado en fuentes primarias (informes oficiales, cables, desclasificaciones) y evaluado con un criterio explícito y comparable.

- **321 casos** · **58 países** · tiers de evidencia **S/A/B = 65 / 114 / 142**
- **Modelo de probabilidad MECE**: cada caso de incidente reparte el 100 % sobre 6 narrativas mutuamente excluyentes y exhaustivas (mundano/natural, humana clasificada, adversaria, no-humano encubierto, no-humano abierto, indeterminado). Probabilidades **comparables** entre casos, no calibradas como frecuencias.
- **Transparencia del juicio**: la vista `/probabilidades` expone cómo se pondera cada narrativa (estándar ICD-203).

## Vistas principales

- **Atlas** — mapa global georreferenciado de los casos.
- **Cobertura** — matriz país × década: dónde el corpus es denso y dónde está flaco.
- **Patrones** — 19 patrones recurrentes documentados a lo largo del corpus.
- **Frameworks** — 11 marcos teóricos comparados.
- **Investigadores** — el ecosistema de la divulgación (91 actores) enlazado a sus casos.
- **Laboratorio** — explorador interactivo (pivot, heatmap, series) sobre el corpus.

## Bajo el capó

- Next.js 14 (App Router) + TypeScript strict, **export estático puro** (SSG) desplegado en GitHub Pages.
- Fuente de verdad: un archivo JSON por caso, con validación de schema, auditorías de consistencia (MECE, cobertura, longitud editorial) y de diseño (contraste WCAG AA) en cada build.
- Bilingüe español / inglés, con estándar editorial de ~1 página por caso en ambos idiomas.

## Estándar editorial

Cada caso nace cumpliendo la disciplina del proyecto: investigación con fuentes primarias, prosa de al menos ~550 palabras por idioma, y una conclusión **deliberadamente en suspenso** cuando la evidencia no alcanza. La consigna es separar el dato duro del relato montado encima.
